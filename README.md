
# Student Management REST API

A RESTful CRUD API built using **Spring Boot, Spring Data JPA, and MySQL**.

## Features
- Create, retrieve, update, and delete students.
- DTO-based request and response handling.
- Input validation using Jakarta Validation.
- MySQL database integration.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Run the Project
1. Configure MySQL credentials in `application.properties`.
2. Create the `student_management` database.
3. Run `StudentManagementApplication.java`.
